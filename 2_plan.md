# 90-Day Plan 🗺️

**Daily rhythm (same every day):**
1. **Notebook math puzzle** (15 to 20 min, no code)
2. **Matching LeetCode problem**, coded in C++ (plus a Codeforces one when you feel like it)
3. **One C++ concept** the problem needs (`vector`, `unordered_map`, references, and so on)

**Every 7th day:** a lighter review day. Redo one old problem from scratch and try one easy Codeforces problem.

| Days | Topic | Math flavor |
|---|---|---|
| 1-12 | Arrays and hashing | Pairs, counting, complements |
| 13-22 | Two pointers and sliding window | Ranges, sums, sorted order |
| 23-30 | Math problems | Divisibility, GCD, primes, modulo |
| 31-40 | Stack, queue, linked list | Matching brackets, sequences |
| 41-48 | Binary search | Halving, logarithms |
| 49-56 | Recursion and backtracking | Counting, permutations, combinations |
| 57-64 | Trees and heaps | Recurrences, levels |
| 65-74 | Graphs (BFS/DFS) | Grids, connectivity |
| 75-84 | DP and greedy | Recurrence formulas, optimal choices |
| 85-90 | Review and mock contests | Mixed |

Tomorrow (Day 2) continues the pairs and complements theme, so you can build on today's puzzle.
